# ฟังเพลงกับ chok (listen-together)

เปิดเว็บเดียว ค้น/วางลิงก์เพลง YouTube หรือ YouTube Music เพิ่มเข้าคิว แล้วทุกคนในห้องได้ยินเพลงเดียวกันพร้อมกัน
ใครในห้องก็กด เล่น / หยุด / ข้าม / เลื่อน / ลบเพลง ได้ และทุกเครื่องจะเปลี่ยนตามทันที

## รัน

```bash
npm install
npm start          # http://localhost:3000
npm test           # เทส logic ห้อง + การตรวจ input
```

ถ้าต้องการให้ค้นเพลงด้วยชื่อได้: copy `.env.example` เป็น `.env` แล้วใส่ `YOUTUBE_API_KEY`
(Google Cloud Console → เปิด YouTube Data API v3 → Credentials → API key) — โควต้าฟรีค้นได้ ~100 ครั้ง/วัน
ถ้าไม่ใส่ key: วางลิงก์เพลงแทนได้ (YouTube Music → แชร์ → คัดลอกลิงก์)

## ทำงานยังไง

```
ปุ่มใดๆ ─► socket 'action' ─► server/room.js (reduce) ─► broadcast 'state' ─► ทุกเครื่อง
                                                                         │
            public/sync.js ทุก 0.4 วิ: เทียบตัวเล่นกับ "ตำแหน่งที่ห้องควรอยู่" ─┘
            คลาดเกิน 0.3 วิ → seek (มี cooldown 2.5 วิ กัน seek รัวช่วงโฆษณา/โหลด)
```

- **server/room.js** — สถานะห้องแบบ pure function เก็บ `position` ณ `refTime` แทน "วินาทีปัจจุบัน"
- **public/clock.js** — วัดว่านาฬิกาเครื่องนี้ต่างจาก server เท่าไร (ping 5 ครั้ง เอา rtt ต่ำสุด)
- **public/ui.js** — วาด UI ทั้งหมด (textContent เสมอ) · **icons.js** — ไอคอนจาก sprite ใน index.html
- เพลงที่ห้ามฝัง (error 101/150) → ติดป้ายแล้วข้ามทั้งห้องอัตโนมัติ

## เมื่อคิวหมด (ปุ่มในห้อง)
| โหมด | ทำอะไร |
|---|---|
| แนวเดียวกัน (ค่าเริ่มต้น) | พอเล่นถึงเพลงสุดท้าย server ค้นเพลงศิลปินเดียวกันมาเติม 3 เพลง **ล่วงหน้า** (ไม่มีช่วงเงียบ) ถ้าค้นไม่ได้ → วนคิว |
| วนคิว | จบเพลงสุดท้าย → กลับเพลงแรก |
| หยุด | จบแล้วหยุด เพลงที่เพิ่มต่อเล่นทันที |

ศิลปินเดาจาก: ช่อง `… - Topic` (ช่องศิลปินจริงของ YT Music) ไม่งั้นใช้ชื่อเพลงที่ตัดวงเล็บ/Official MV แล้ว
งบ: ห้องละ 1 ครั้ง/30 วิ และทั้ง server ไม่เกิน 40 ครั้ง/วัน (~40% ของโควต้า) — ปรับได้ที่ `AUTOFILL_*` ใน `server/index.js`
- debug: เปิด `?debug=1` แล้วพิมพ์ `__lt.drift()` ใน console

## ข้อจำกัดที่รู้อยู่
- ห้องเก็บในหน่วยความจำ — restart server แล้วคิวหาย
- คนที่ใช้ Chrome ไม่มี adblock อาจเจอโฆษณา (เครื่องนั้นพลาดเพลงช่วงนั้น แล้ว seek ตามเองเมื่อโฆษณาจบ)
- มือถือ: ปิดจอ/สลับแอป เพลงหยุด (ข้อจำกัดของ YouTube embed)
- เพื่อนนอกวง LAN จะเข้าได้ต้อง deploy (Render / Fly.io) หรือเปิด tunnel เช่น `cloudflared tunnel --url http://localhost:3000`
